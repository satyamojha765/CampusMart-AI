# CampusMart AI

CampusMart AI is a GenAI-powered creative copilot for student creators,
campus vendors and small businesses.

## Features

- AI Caption Generator
- Reel Script Generator
- Visual Prompt Builder
- Campaign Content Generator
- Customer Reply Assistant
- Prompt Presets
